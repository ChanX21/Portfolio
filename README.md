# Chanchal Delson Portfolio

Frontend-only Astro portfolio for Chanchal Delson.

## Commands

```sh
npm install
npm run dev
npm run check
npm run build
```

The live dev server runs at `http://localhost:4321/`.

## Content

- Profile, stack, and links: `src/content/profile.ts`
- Experience: `src/content/experience.ts`
- Projects: `src/content/projects.ts`
- Portfolio page data: `src/content/portfolio.ts`
- Curated social posts: `src/content/social.ts`
- Blog posts: `src/content/blog/*.md`

LinkedIn/X content is curated locally for V1. Real sync needs a backend or build-time ingestion with API credentials.
